# 绯红星云 · 粒子星球

这是一个可直接运行的单页面场景，使用 Three.js CDN 渲染：
- 12800 个粒子构成红色星球
- 深黑宇宙背景与稀疏星点
- 鼠标拖拽旋转、滚轮缩放
- 底部半透明 HUD：粒子数量 / 当前视角 / 缩放级别
- 深邃、梦幻、科幻色调

## 运行

直接双击 `index.html` 打开即可（前提是网络可访问 CDN）。

如果你希望本地离线运行，可将 `three.min.js` 下载至本地后替换为本地引用。
